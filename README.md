# SpendWise

SpendWise is a personal finance management web application built using the MERN stack. It helps users manage their expenses, set monthly budgets, and understand their spending through a simple dashboard and analytics.

## Features

- User registration and login with JWT authentication
- Protected routes for authenticated users
- Add, edit, and delete expenses
- View personal expense history
- Create, edit, and delete monthly budgets
- Budget spending and remaining amount tracking
- Budget warning when spending reaches the defined threshold
- Dashboard with financial summaries
- Recent expense overview
- Spending analytics by category
- Spending trend visualization
- Budget vs actual spending comparison
- User profile section
- Responsive UI for desktop, tablet, and mobile
- Soft purple themed interface

## Tech Stack

### Frontend
- React.js
- React Router
- Redux Toolkit
- JavaScript
- Tailwind CSS

### Backend
- Node.js
- Express.js
- MongoDB
- Mongoose
- JSON Web Token (JWT)
